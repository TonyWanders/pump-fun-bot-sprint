Momentum bot for the Pump.fun Bot Sprint. It reads the replay of pump.fun bonding curve events, buys coins that break out early on buy dominated flow, and exits with discipline: sell half at plus 50 percent, sell the rest at plus 120 percent, trail 20 percent below the peak after the first take profit, stop out at minus 20 percent, and dump a flat coin after 60 trades. Standard library only, fully deterministic, no network, no clock, no randomness.

## Run it

```sh
python3 main.py
```
